# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-08-24

### Added
- Initial release of AI Stock Trader
- Technical indicators module with RSI, MACD, Bollinger Bands, Moving Averages, ATR, OBV, ROC, and Stochastic
- AI Engine with multi-indicator analysis and signal generation
- Portfolio management system with position tracking and P&L calculation
- Risk management module with stop loss, take profit, and position sizing
- Trade simulator with realistic slippage and commission modeling
- Backtesting engine for strategy validation
- Live trading loop with real-time analysis
- Interactive Streamlit dashboard for monitoring
- Comprehensive unit tests
- Configuration system with YAML support
- Logging and utility modules

### Features
- Real-time stock data fetching via yfinance
- Advanced technical analysis with 8+ indicators
- AI-driven buy/sell signal generation
- Multi-symbol portfolio management
- Risk controls with daily loss limits
- Backtesting with performance metrics (Sharpe ratio, max drawdown, win rate)
- Web-based dashboard with charts and analytics
- Modular architecture for easy customization
